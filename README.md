**StudySphere** is a multi-user, all-in-one MERN learning platform designed for universities, bringing courses, lessons, quizzes, assignments, discussions, notes, and academic resources into a single platform.

### ✨ Highlights

* 🔐 **JWT Authentication** with secure user sessions
* 👥 **Role-Based Access Control** for Student, Educator, and Admin roles
* 📖 **Course & Lesson Management** with semester-organized learning content
* 📤 **File & Video Uploads** powered by Cloudinary
* 📝 **Quizzes & Auto-Grading** for interactive assessments
* 💬 **Lesson Discussions** for student–faculty interaction
* 📅 **Assignment Tracking** with deadline-focused workflows
